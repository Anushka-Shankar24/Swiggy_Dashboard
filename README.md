# 🍔 Swiggy Sales Dashboard — MS Excel

An interactive **Swiggy Sales Dashboard** created using Microsoft Excel to analyze sales performance, orders, customer ratings, food types, cities, and states.

## 📊 Project Overview

This project transforms raw Swiggy order data into an interactive dashboard using **Pivot Tables, Pivot Charts, KPIs, and Filters**.

The dashboard helps understand overall sales performance and identify trends across different time periods, food types, states, and cities.

## 🎯 Objectives

- Analyze total sales and order performance
- Track monthly and daily sales trends
- Analyze sales by food type
- Compare state-wise sales performance
- Identify the top-performing cities
- Monitor customer ratings
- Calculate Average Order Value (AOV)

## 📌 Key KPIs

- **Total Sales**
- **Average Rating**
- **Average Order Value (AOV)**
- **Rating Count**
- **Total Orders**

## 📈 Dashboard Visualizations

1. **Monthly Sales Trend** — Tracks sales performance month-wise
2. **Daily Sales Trend** — Analyzes daily sales fluctuations
3. **Total Sales by Type** — Compares Veg and Non-Veg sales
4. **State-wise Sales** — Shows sales distribution across states
5. **Top 5 Cities by Sales** — Identifies the highest-performing cities
